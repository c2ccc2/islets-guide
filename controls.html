ISLETS · CONTROLS

操作与按键说明

Iko 操控简单、移动响应快；支持键鼠、PlayStation、Xbox、Switch Pro 等主流输入设备。本页给出官方对应关系，方便你切换平台或对照攻略时一眼看懂。

操作说明 最后校验：2026-09-01 阅读约 3 分钟
说明：原版游戏无中文按键显示；本表键位以 Steam 默认（键鼠）和三大主机标准布局为准。如果你改了键位，可在游戏暂停菜单的"Options → Controls"里重新映射。

飞艇战斗（空中）

空中 Boss 战与地面操控差别较大，标准手柄布局如下：

动作XboxPlayStationSwitch键鼠
推进右摇杆 R（按住）R2（按住）ZR（按住）W 持续按
开火 / 射击RT（按住）R1（按住）ZR 或 ZR+ZR鼠标左键（按住）
转向左摇杆左摇杆左摇杆鼠标移动 / A D

小贴士：前期飞艇（如空中海盗战）没有武器，胜负全靠"等敌方反弹弹回自己"的窗口；后期才解锁飞艇炮与短距传送。飞艇命中判定是机舱中心的红圈，并非整艘船。

输入设备支持

  • 完整支持：Xbox One / Xbox Series 手柄、PlayStation DualShock 4 / DualSense、Switch Pro Controller
  • Steam Input 映射可用；可在 Steam 控制器设置里自定义摇杆曲线
  • 键鼠延迟低，对精准弓箭与下劈更友好
Note: Islets does not localize button prompts. The tables below use the standard layout on each platform. You can rebind any action in Options → Controls.

Airship combat

Airship fights feel like bullet-hell sections, so the mapping differs from the ground game:

ActionXboxPlayStationSwitchKeyboard
ThrustHold RTHold R2Hold ZRHold W
Fire / shootHold RT (post-upgrade)Hold R1Hold ZRHold LMB
SteerLeft stickLeft stickLeft stickMouse / A D
Short teleport (late)Tap XTap □Tap YTap Space
Tip: Early airship battles (e.g. Sky Pirates) have no weapon — you win by dodging until the boss's boomerang shot returns to damage it. Later upgrades add a cannon and a short-range teleport. Your hitbox is the small inner circle, not the whole ship.

Input support

  • Full support: Xbox One / Series, DualShock 4 / DualSense, Switch Pro Controller
  • Steam Input remapping available
  • Mouse + keyboard is the most precise option for arrows and plunges
